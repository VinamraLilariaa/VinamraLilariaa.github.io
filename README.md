# Personal Profile Website

HTML + CSS personal profile webpage for GitHub Pages.

## Files
- `index.html` — webpage structure and content
- `style.css` — styling and responsive layout
- `images/profile-placeholder.svg` — temporary profile image

## Before publishing
1. Replace the placeholder image with your own photo.
2. Update the GitHub and LinkedIn links in `index.html`.
3. Test the page locally.
4. Upload the files to a public GitHub repository.
5. Enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
